# 12.0 reference-host wire capture

What engine 12.0's reference host, Aras's `ConsoleUpgrade.exe` 12.0 (`spec/wire.md`, WIRE-002), sends below the AML, recorded once against dev for ticket 46. The oracle transcripts hold only the AML given to `CallAction` and the response envelope, so this capture is the evidence for the request framing, headers, OAuth discovery and token exchange, and logoff of IOM 12 (`[12.0]` of WIRE-003 to WIRE-040). It is the counterpart of `../14.0.7-reference-host/`.

- **Run:** a one-item export (`com.aras.innovator.servicereporting`, `List` "Report Format Types") through `oracle/wire-capture/`: `ReferenceHost-12.0.cs` connects as ConsoleUpgrade 12.0 does with the vendored 12.0 `Libs.dll` and `IOM.dll` (the four-argument `HttpConnectorExtension`, `CItemHelper.Login()`, one export, `CItemHelper.logout()`), and `proxy.mjs` records every exchange between it and the dev server (`http://localhost:18089/12sp9` forwarded to dev, database `12sp9`, user `admin`).
- **`capture.jsonl`:** one exchange per line, in order: `seq`, `request` (`method`, `url`, `httpVersion`, `headers` as `[name, value]` pairs in wire order, `body`) and `response` (`status`, `headers`, `body`).
- **Exchanges:** 1 and 2 discovery and the OpenID configuration (no key-set request); 3 the password grant; 4 `ValidateUser`; 5 `GetCurrentUserID`; 6 IOM's user record read; 7 and 8 the version probe (two requests); 9 to 31 the export's requests; 32 `Logoff`. The 14.0.7 capture has 35: it adds the key set, two probe requests and the float-property lookup of `Value`, and has no `GetCurrentUserID`.
- **Edits made to the recording:** as for 14.0.7. Scrubbed: the password digest in the token request, the access token in its response and in every `Authorization` header (`SCRUBBED`, `SCRUBBED_TOKEN`), and the `ASP.NET_SessionId` cookie value. The discovery response's `uri` points at the OAuth server's host without the proxy's port; the proxy rewrote it to its own origin, so the token exchange went through it. `body` is what the server sent; `clientBody` is what the host received. Response bodies above 16 KiB are replaced by `{ "length", "sha256" }`. Request bodies are complete.

Re-record with `oracle/wire-capture/` (see the header of `capture-12.0.ps1`), then `ARAS_PASSWORD=… npx tsx oracle/wire-capture/fixture.ts <raw.jsonl> capture.jsonl`.
