# opt-timeout-30000

Option: Timeout 30000. Engine 14.0.7, export, recorded on dev (read-only). Catalogue: Timeout (ticket 05).

## Exercises

A positive timeout, recorded only.

## Input

The engine's `selItemsTable` is a `Hashtable` from package to a `Hashtable` of items. The host fills it in this order: a package on its first item, then each item under its id. `run.json` holds the same list as `params.Items`.

| # | Package | Type | Id | Keyed name |
|---|---|---|---|---|
| 1 | com.aras.innovator.history | Grid | 4B9FF34674E34677B877FC8F71B5CDBE | History_whereTemplateUsed |

Engine options: `timeout` = `30000`.

## Result

The export completes: host exit 0, 21 calls.
