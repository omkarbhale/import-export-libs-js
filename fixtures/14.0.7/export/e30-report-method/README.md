# e30-report-method

Report: method (BOM Costing Report). Engine 14.0.7, export, recorded on dev (read-only). Catalogue: E30 (ticket 05).

## Exercises

The Report method becomes a get by keyed_name.

## Input

The engine's `selItemsTable` is a `Hashtable` from package to a `Hashtable` of items. The host fills it in this order: a package on its first item, then each item under its id. `run.json` holds the same list as `params.Items`.

| # | Package | Type | Id | Keyed name |
|---|---|---|---|---|
| 1 | com.aras.innovator.solution.PLM | Report | B932166880F84F30BB02C62E0C29CBEF | BOM Costing Report |

Engine options: none; every one keeps the engine's default.

## Result

The export completes: host exit 0, 16 calls.
