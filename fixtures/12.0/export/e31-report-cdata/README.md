# e31-report-cdata

Report: report_query and xsl_stylesheet as CDATA (ECN Report). Engine 12.0, export, recorded on dev (read-only). Catalogue: E31 (ticket 05).

## Exercises

report_query and xsl_stylesheet are written as CDATA; no method.

## Input

The engine's `selItemsTable` is a `Hashtable` from package to a `Hashtable` of items. The host fills it in this order: a package on its first item, then each item under its id. `run.json` holds the same list as `params.Items`.

| # | Package | Type | Id | Keyed name |
|---|---|---|---|---|
| 1 | com.aras.innovator.solution.PLM | Report | 70007FC2534243EEBC63B0F988F4AE6B | ECN Report |

Engine options: none; every one keeps the engine's default.

## Result

The export completes: host exit 0, 14 calls.
